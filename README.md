# Thumbs Mood Reader

A p5.js + ml5.js (handPose) sketch that reads your thumb through the webcam.
Hold the gesture for about a second:

- Thumbs up: "I'm glad you're feeling great!"
- Thumbs sideways: "Well, at least you're not thumbs down."
- Thumbs down: plays a YouTube video.

Run it from a web server (GitHub Pages, or `python3 -m http.server` in this folder), not by opening index.html as a file, and allow camera access.
